# File Browser fork v2.64.1

- Set `FB_WEBAUTHN_ORIGIN=https://files.example.com` on the server or container
  to configure FIDO2 automatically when File Browser starts. Works with an
  existing database; no maintenance container is needed.
- Removing the startup setting leaves the saved origin in place. The
  existing enrollment protection still rejects a hostname change while
  users have registered keys.
- [WebAuthn setup](../authentication.md#passwordless-security-keys-webauthn)
  and [Docker deployment](../deployment.md).
