# File Browser fork v2.64.0

- Optional passwordless sign-in with FIDO2 security keys, including compatible
  YubiKeys. Enrolled accounts cannot sign in with their previous password.
- Register a backup key, or return to password login by setting a new password.
  Administrators can remove keys for another account, with fresh confirmation.
- [Setup and recovery](../authentication.md#passwordless-security-keys-webauthn).
  Back up the database before enabling the feature.
- This fork publishes binary archives and SHA-256 checksums on GitHub. It does
  not publish to the original project's Docker Hub or Homebrew destinations.
- Release CI uses a virtual FIDO2 device and a disposable Linux deployment; it
  is not a substitute for checking a physical key on your deployment.
